# QuizBall ⚽

Пошаговый онлайн-футбол 3 на 3, где каждое действие (пас, дриблинг, удар) разыгрывается через викторину. Сложность вопроса зависит от дистанции и количества защитников на линии. Защитники, оказавшиеся на пути паса или удара, получают ту же викторину одновременно — кто первый ответит верно, тот побеждает в эпизоде.

## Стек

- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind 4 для стилей, Framer Motion для анимаций поля и викторины
- Socket.IO поверх кастомного Node-сервера для real-time мультиплеера
- Локальный банк футбольных вопросов + догрузка из Open Trivia DB (категория Sports)

## Запуск

```bash
npm install
npm run dev
# → http://localhost:3000
```

Откройте две вкладки/устройства: создайте комнату из одной, скопируйте ссылку и зайдите со второй — матч стартует автоматически.

## Правила прототипа

- Поле 8×5, по 3 игрока в команде. Команда A слева атакует вправо, B — наоборот.
- На ходу владеющего мячом игрока доступны три действия:
  - **Пас** партнёру: легко при коротком пасе без защитников, сложнее при длинном пасе и/или защитниках на линии.
  - **Дриблинг** на 1 клетку: всегда лёгкий вопрос.
  - **Удар** по воротам (только из последних 3 колонок чужой половины): сложность зависит от дистанции и блокирующих защитников.
- Викторина показывается одновременно атакующему и всем защитникам на пути. Первый верный ответ забирает эпизод. Если никто не успел — мяч отходит к ближайшему сопернику.
- Матч до 3 голов.

## Структура

```
app/
  page.tsx                 — лобби, список открытых комнат
  game/[roomId]/page.tsx   — игровой экран
components/
  Pitch.tsx                — SVG-поле с анимированным мячом и игроками
  QuizModal.tsx            — оверлей викторины
  Scoreboard.tsx           — счёт и индикатор хода
  ActionPanel.tsx          — выбор действия
  GameLog.tsx              — лента событий
lib/
  game/
    types.ts               — общие типы
    engine.ts              — чистая игровая логика
    quiz.ts                — банк вопросов + Open Trivia DB
    room.ts                — состояние комнат и lifecycle викторины
  socket-events.ts         — типизированные события клиент/сервер
hooks/useSocket.ts         — singleton-сокет для всех страниц
data/questions.ts          — локальные футбольные вопросы (easy/medium/hard)
server.ts                  — кастомный Node-сервер (Next + Socket.IO)
```
